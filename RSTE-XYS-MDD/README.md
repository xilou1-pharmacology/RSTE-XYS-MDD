# Role-Stratified Target Enrichment (RSTE)

Code and analysis scripts for:

> **Role-Stratified Target Enrichment of Xiaoyao San: herb-specific pharmacology and
> compartment-divergent immuno-metabolism in major depressive disorder**

---

## Quick start

```bash
git clone <this-repo>
cd RSTE-XYS-MDD
pip install -r requirements.txt
python rste/10_rste.py          # reproduces the RSTE enrichment, ground truth and null model
python figures/fig1.py          # then any figure script
```

All paths resolve from the repository root through `config.py`; nothing is hard-coded.
Outputs are written to `results/` and `figures/`.

The R scripts expect the working directory to be the repository root, since they
`source("config.R")`.

## What is included

| Path | Contents |
|---|---|
| `rste/10_rste.py` | RSTE: herb-level unique target sets, herbal-universe background, hypergeometric enrichment with BH-FDR, seven ground-truth associations, size-matched null model |
| `analysis/` | Pathway convergence, cis-eQTL Mendelian randomization, antidepressant-target overlap, Figure 3 data |
| `figures/` | One script per figure; `fig_style.py` holds the shared style |
| `R/` | Library construction, target assembly, limma differential expression, single-cell processing, null model |
| `data/processed/` | Derived tables used by the scripts (see below) |
| `data/raw/kegg/` | KEGG and GO gene sets (public) |
| `results/` | Analysis outputs read by the figure scripts |

### Derived tables in `data/processed/`

These are products of this work, built from TCMSP 2.3 and HIT with OB ≥ 30% and DL ≥ 0.18,
and are redistributed here so that every figure can be regenerated without re-downloading
the source databases.

| File | Size | Content |
|---|---|---|
| `herb_targets_v2.tsv` | 1.7 MB | herb → target mapping for all 603 reference herbs |
| `compound_target_edges.tsv` | 107 KB | 122 compounds, 241 targets, 2,539 edges |
| `XYS_targets_OB30DL018.tsv` | 2 KB | the 241 filtered targets |
| `formulas.tsv` | 105 KB | the seven formulae and their herb composition |
| `deg_128vs64.tsv` | 2 MB | limma results, GSE98793 |
| `immune_ssgsea.tsv`, `pheno_GSE98793.tsv` | 52 KB | ssGSEA scores and sample annotation |
| `ppi_degree.tsv` | 2 KB | STRING degree per target |
| `metabolomics_ST000062.tsv` | 5 KB | plasma metabolite statistics |
| `scrna_gene_mono_ratio.rds` | 397 KB | monocyte-to-other expression ratio per gene |

### Datasets you must download yourself

The large primary data are not redistributed; download them from the sources below and
place them under `data/raw/`.

| Data | Source | Destination |
|---|---|---|
| Bulk transcriptomes (128 cases / 64 controls) | GEO **GSE98793** | `data/raw/GSE98793/` |
| Expression matrix for the ROC analysis | generated by `R/05_build_deg_GSE98793.R` | `data/processed/expr_blood_full.tsv` |
| Single-cell PBMC (9 patients, 33,833 cells) | GEO **GSE336230** | `data/raw/GSE336230_harmony.rds` |
| cis-eQTL summary statistics | eQTLGen, `cis-eQTLs_full_20180905.txt.gz` | `data/raw/mr/eqtlgen_cis_eQTL_FDR05.txt.gz` |
| Depression GWAS | FinnGen R12, endpoint `F5_DEPRESSION` | `data/raw/mr/finngen_R12_F5_DEPRESSION.gz` |
| Plasma / CSF metabolomics | Metabolomics Workbench **ST000062**, **ST000063** | `data/raw/metab/` |
| Docking structures | PDB **2AZ5** (TNF), **5IKQ** (PTGS2), **3O96** (AKT1) | `data/raw/pdb/` |

TCMSP 2.3 is required only to rebuild the derived tables from scratch
(`R/02`–`R/04`); set `RSTE_TCMS_DIR` to its location.

## Reproducing the figures

```bash
python figures/fig1.py       # Figure 1  RSTE framework
python figures/fig2_v4.py    # Figure 2  composition and connectivity
python figures/fig3.py       # Figure 3  formula specificity
python figures/fig456.py     # Figures 4-6
python figures/fig7_v2.py    # Figure 7  compartment-resolved metabolomics
python figures/fig8_v3.py    # Figure 8  docking

python analysis/diagnostic_ML.py        # target-set score and AUC (needs expr_blood_full.tsv)
python analysis/background_comparison.py  # background substitution and ablation numbers
```

Each writes a vector PDF and a 300 dpi PNG into `figures/`.

## A note on the two target universes

RSTE operates on the unfiltered herb-level target sets (1,130 genes), because uniqueness is
defined per herb and an OB/DL filter would remove the discriminating targets. All disease-side
analyses use the OB/DL-filtered set (241 genes). The consequences of this split are quantified
in the Results section *From RSTE output to the disease set*.
